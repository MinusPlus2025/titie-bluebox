# 体贴｜Brand System V2
更新时间：2026-08-29

## 1. 品牌基础

**品牌名**：体贴  
**Slogan**：**知冷暖，好好睡。**

### 产品定位
体贴是一款面向睡眠场景的**个体化身体温感与分区调节产品**。  
它不是寻找一个统一的标准温度，而是根据身体不同位置的变化、床内微环境以及用户自己的反馈，判断哪里需要暖一点、哪里需要凉一点、哪里刚刚好。

### 品牌理念
体贴，不是替人决定什么最舒服。  
而是慢慢知道，什么对她刚刚好。

### 价值观
**看见 · 回应 · 不打扰**
- **看见**：看见细小的身体差异和睡眠状态变化。
- **回应**：只回应真正需要调整的部位。
- **不打扰**：刚刚好就保持，拿不准就少做一点。

## 2. 与蓝盒子品牌关系

蓝盒子本身以**蓝色**为品牌识别。  
体贴作为蓝盒子命题下的产品，不应脱离母品牌，而应该在“睡眠、科技、安静、可信”的语境里，基于蓝色做延展。

### 视觉策略
不直接复制“品牌蓝 + 科技渐变”的常规做法，而是将蓝色分成三个层级：
1. **品牌识别蓝**：用于品牌主识别、重点按钮、关键状态。
2. **静息蓝灰**：用于大面积背景和界面基底，让产品更安静。
3. **语义冷暖色**：用于“建议暖一点 / 建议凉一点”的局部提示，避免整屏大红大蓝。

## 4. Logo 构思方向

### 方向原则
Logo 不做“月亮 + 星星 + 女性符号”的直白套路，也不做过度科技的几何图标。

### 建议结构
**符号 + 文字标志**

#### 符号灵感
从三个概念提取：
- 包裹 / 覆盖（被褥、床、照顾）
- 身体曲线（睡眠中的身体感）
- 分区与流动（冷暖微调）

#### 推荐符号
一个**圆角矩形 / 柔和盒形轮廓**，内部是一条连续的流线，像一张被子轻轻包裹住躺着的身体，同时也像“冷暖流动的路径”。

这个符号既回应“蓝盒子”的盒形品牌基因，又保持“体贴”的柔和与睡眠感。

#### 文字标志
“体贴”两字可用更有气质的中文标题字，但正文 UI 依旧使用无衬线。
英文或辅助文案统一无衬线。

## 6. Typography

### 品牌字
- 标题/品牌名：可用更有气质的中文字体表现“体贴”
- UI 正文：`PingFang SC, Noto Sans SC, system-ui`

### 字号建议
- Hero 标题：40–48
- 区块标题：24–28
- 正文：15–17
- 说明：12–14

原则：
- 信息清晰、层次稳定
- 不做海报式 80–100px 巨字
- 不用全大写科技词

## 7. UI 视觉原则

1. **身体是主视觉，不是图表。**
2. **先看感受，再看技术。**
3. **默认安静，状态点到为止。**
4. **知道的时候回应，不知道的时候不打扰。**

### 组件气质
- 轻边框
- 少阴影
- 中等圆角（16–24px）
- 有留白
- 不胶囊滥用
- 不玻璃拟态

---

## 8. 文案原则

### 推荐表达
- 建议暖一点
- 建议凉一点
- 刚刚好
- 轻轻暖一下
- 稍微凉一点
- 先不调整，继续观察
- 5分钟后再看看
- 记住了
- 拿不准的时候，少做一点

### 避免表达
- AI读懂你
- 检测到你膝盖冷
- 女性最佳温度
- 精准识别女性身体
- Personal Model Updated
- Thermal Preference Engine

## 9. 视觉应用

### 首页 / Tonight
视觉中心是**床上的睡眠身体**和“今晚整体很稳定 / 2个位置需要轻微调整”。

### 早晨反馈
使用同一身体图，保持品牌连续性。

### 技术验证
视觉延续一致，但语气更理性，先讲清楚三种策略，再给数字。
