# PRODUCT_LANGUAGE.md — 「体贴」的语言与女性中心设计

## 总原则
产品面对的是一个具体的人，而不是“女性”这个统计标签。

研究可以讨论周期、潮热、更年期等热调节变化，但产品语言不能把群体研究直接变成对用户身体的预设。

## 用户界面优先使用
- 暖一点
- 刚刚好
- 凉一点
- 今晚哪里最需要调整？
- 如果你愿意，可以补充今晚有什么不同
- 这里的状态和你过去选择“暖一点”时比较接近
- 房间温度没有明显变化，所以系统优先考虑局部调整
- 收到。下次遇到相似状态，会把你的选择算进去
- 暂时不调节，继续观察
- 这一判断置信度较低，因此保持不动

## 后台可使用
WARM / HOLD / COOL / thermal preference / thermal sensation / local thermal condition / personal calibration / confidence / hysteresis。

## 避免
- 女性的身体不止一个温度
- AI读懂她的身体
- 系统知道你冷
- 你的膝盖异常
- 经期需要腹部加热
- 女性更敏感所以……
- 最佳女性温度
- 你的身体应该……
- AI已经学会你

## 替换为
- 同样的环境，对每个人的感受可能不同
- 这里可能需要暖一点
- 这次判断来自当前变化和你过去的反馈
- 周期信息只在你愿意提供时作为参考
- 你可以随时纠正

## 品牌表达
产品名：**体贴**

副标题：**个体化身体温感与分区调节系统**

推荐主表达：**让冷暖跟着你，不必让你迁就温度。**

推荐第二表达：**哪里需要暖一点，哪里需要凉一点，哪里刚刚好。**
