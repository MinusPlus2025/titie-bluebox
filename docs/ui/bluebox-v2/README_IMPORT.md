# 体贴｜前端实现说明 V2

## 1. 这份交付是什么
这是基于蓝盒子蓝色品牌延展后的：
- 品牌视觉体系
- UI/UX 规范
- 样例前端原型代码

## 2. 文件结构
- `docs/brand/TITIE_BRAND_SYSTEM_V2.md`
- `docs/ui/TITIE_UI_UX_BLUEBOX_V2.md`
- `docs/ui/COPY_DECK_BLUEBOX_V2.md`
- `prototype/index.html`
- `prototype/styles.css`
- `prototype/app.mjs`

## 3. 如何接到现有体贴项目
如果交给 Codex：
1. 先阅读 docs 三份文档。
2. 将 `prototype` 里的结构迁移到现有 Vite 前端。
3. 不重写现有 Engine / Validation / Personalization 业务逻辑。
4. 使用这套视觉 tokens 替换旧版样式。
5. 将目前静态文案与演示数据改为真实模块输出。

## 4. 当前原型特点
- 采用蓝盒子延展蓝色系统
- 以床上俯视睡眠身体为主视觉
- Tonight 为核心产品中心
- 右侧 Drawer 显示区域原因
- 早晨反馈和技术验证保持统一语言

## 5. 运行
直接打开 `prototype/index.html` 即可预览静态原型。
如需放到 Vite，可直接迁移为组件。
